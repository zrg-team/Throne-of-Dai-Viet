# Vạn Thắng — approved river icon pack

- `ios/AppIcon.appiconset`: universal default/tinted catalog generated by Expo. `ios/app-store-icon-1024.png` is the opaque marketing image.
- `android/res`: five density families, foreground/monochrome layers, legacy launchers, adaptive XML and background color. Preserve resource names; reference `@mipmap/ic_launcher` and `@mipmap/ic_launcher_round`.
- `android/play-store-icon-512.png`: sRGB, 32-bit PNG under 1024 KB.
- `expo`: source images and an icon configuration excerpt to merge into the app's existing configuration.
- `web`: favicons, ICO, Apple touch icon, regular/maskable PWA icons, menu emblem and manifest. URLs are relative to the manifest location.

Browser favicons use the detailed boat's transparent foreground. Use the fresh `favicon-river-v9*` URLs to replace cached tab artwork. The established favicon filenames contain the same transparent exports. The simplified V8 proposal is not included.

Square artwork has no baked corner masks. Default images retain the approved drawing; separate derivatives support masking and tinting. The supported iOS PNG workflow is used; no custom dark or Icon Composer file is included.

The project is already configured. Installed mobile icons require a new native build; live web and store changes require deployment/upload. No release was performed.

![Platform preview](preview.png)

The original approved artwork and its transparent derivatives are in `sources/`. Validation results are in `verification.json`.

Requirements checked against [Android adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive), [Google Play icon specifications](https://developer.android.com/distribute/google-play/resources/icon-design-specifications), [Expo's iOS integration](https://docs.expo.dev/develop/user-interface/splash-screen-and-app-icon/) and [MDN web icon guidance](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Define_app_icons).
